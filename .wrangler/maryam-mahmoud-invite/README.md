# دعوة محمود ومريم — ملفات التسليم

- `index.html` — الدعوة شغالة كاملة. افتحها في أي متصفح (كروم أو سفاري) على الكمبيوتر أو الموبايل.
- `01-PROMPT-build-site.md` — الخطوة ١: تحويل الديزاين لموقع حقيقي responsive من غير أي تغيير في الشكل.
- `02-PROMPT-add-english.md` — الخطوة ٢: إضافة الإنجليزي. نفّذها بعد ما تراجع الخطوة ١.

## لسه ناقص قبل النشر
- آخر موعد لتأكيد الحضور (مكانه `[آخر موعد للتأكيد]`).
- ميعاد الفرح: العداد وملف التقويم معمولين على ٧ مساءً بتوقيت القاهرة.
- الفورمات (الحضور والتهنئة) واجهة بس — محتاجين backend يحفظ الردود.
- الموسيقى: الزرار شكل بس، محتاج ملف الأغنية.
